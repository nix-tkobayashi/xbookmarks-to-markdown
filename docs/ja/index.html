X Bookmarks to Markdown
使い方 プライバシー GitHub English

保存したブックマークを、
手元に残るファイルへ。

X Bookmarks to Markdown は、ブックマークした投稿を1件1ファイルの Markdown に変換し、ZIP にまとめてダウンロードします。Obsidian や Logseq、好きなエディタにそのまま置けて、アカウントなしで何年後でも読めます。

拡張機能を入手する ソースコードを見る
version
1.6
browsers
Chrome ほか Chromium 系ブラウザ
languages
日本語・英語
license
MIT（ソースは GitHub で公開）

3ステップで、手元のディスクに

アカウント登録もログインも API キーも不要です。いま開いているページをそのまま読み取ります。

  1. ブックマークページを開く

    x.com/i/bookmarks を開きます。ブックマークタグの新しいページ x.com/i/history にも対応しています。

  2. 期間を指定する

    拡張機能のアイコンをクリックし、開始日と終了日を選びます。空のままにすればすべて書き出します。

  3. エクスポートする

    自動でページをスクロールしてすべてのブックマークを読み込み、x-bookmarks.zip を好きな場所に保存します。

ZIP の中身

中身はテキストファイルだけ。独自形式もデータベースもなく、あとから別のツールへ移せます。

x-bookmarks.zip
├── index.md      目次
├── あとで読み返したくて…md
├── この論文がいちばん…md
└── 打ち合わせのメモ…md
1投稿 = 1ファイル
本文の冒頭と投稿 ID からファイル名を作るため、似た投稿どうしが上書きし合うことはありません。
フロントマター
投稿者・投稿日時・元の x.com URL を各ファイルの先頭に記録します。ノートアプリ側でそのまま索引できます。
画像・動画・リンク
投稿に含まれる画像や動画、短縮リンクは見出しごとにまとめて残します。
index.md
書き出したすべてのファイルへのリンク集。解凍した直後から目次として使えます。

この拡張機能ができること・できないこと

権限は3つだけで、それぞれ役割は1つです。拡張機能自身は通信を一切行わないため、ブックマークが端末の外に出ることはありません。

バージョン 1.6 が要求する権限
権限必要な理由
activeTab アイコンをクリックしたときだけ、いま見ているタブにアクセスします。
scripting ブックマークページ上で読み取り用スクリプトを実行し、表示されている投稿を集めます。
downloads できあがった ZIP をブラウザの保存ダイアログに渡します。ダウンロード履歴は読みません。

収集も保存も送信もしません。解析ツールもサーバーも第三者サービスも使わず、書き出しはメモリ上で組み立てて、保存が終われば破棄されます。プライバシーポリシー全文もご覧ください。

インストール

Chrome ウェブストアには申請中です。公開されるまでは、パッケージ化されていない拡張機能として読み込めば1分ほどで使えます。

手動で読み込む

  1. 最新のソース ZIP をダウンロードして展開します。
  2. ブラウザで chrome://extensions を開きます。
  3. 「デベロッパー モード」をオンにします。
  4. 「パッケージ化されていない拡張機能を読み込む」で展開したフォルダを選びます。
  5. アイコンをツールバーに固定し、ブックマークページを開きます。

使う前に

  1. X にログインした状態で使ってください。画面に表示されている内容をそのまま読み取ります。
  2. 自動スクロール中はブックマークのタブを前面のままにしてください。読み込みが終われば自動で止まります。
  3. 件数が多いと数分かかります。完了はポップアップのステータス表示で分かります。

うまくいかないときは

  1. X 側の画面構造は頻繁に変わります。何も書き出されないときは、ページを再読み込みしてもう一度試してください。
  2. それでも解決しなければ、GitHub の Issue で状況を教えてください。
