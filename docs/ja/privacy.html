X Bookmarks to Markdown
使い方 インストール サポート GitHub English

プライバシーポリシー

最終更新 2026年9月9日 / 対象バージョン 1.6

X Bookmarks to Markdown は、X（旧 Twitter）のブックマークを Markdown ファイルとして書き出すブラウザ拡張機能です。処理はすべて利用者の端末内で完結します。

データを収集しません

  • 個人情報、閲覧履歴、利用状況を収集・保存・送信することは一切ありません。
  • アクセス解析、テレメトリ、トラッキングの類は使用していません。
  • 拡張機能自身はネットワーク通信を行わず、サーバー・API・第三者サービスとやり取りしません。

ブックマークの扱い

  • ブックマークの内容は、すでにブラウザで開いている X のページから読み取り、メモリ上で処理します。
  • 生成した Markdown ファイルは ZIP にまとめ、ブラウザの保存ダイアログに渡します。
  • 処理後は何も残しません。拡張機能はブックマークのデータを保持せず、タブを閉じれば破棄されます。
  • 書き出したファイルは利用者のものであり、利用者が選んだ場所にのみ保存されます。

権限

権限用途と範囲
activeTab アイコンをクリックしたときにのみ、表示中のタブへのアクセスを得ます。タブを離れると権限は失われます。
scripting ブックマークページに読み取り用スクリプトを挿入し、表示されている投稿を収集します。対象はアクティブなタブの x.com/i/bookmarks と x.com/i/history のみです。
downloads 生成した ZIP ファイルをブラウザのダウンロード機能で保存します。ダウンロード履歴や既存のファイルを読むことはありません。

第三者サービス

ZIP の作成にオープンソースライブラリ JSZip を同梱して利用しますが、処理はすべてローカルで行われます。外部サービスとの連携、広告表示、第三者へのデータ提供はいずれもありません。

確認する方法

ソースコードは MIT ライセンスで全文公開しています。リポジトリを読んで確かめられるほか、エクスポート中にブラウザの開発者ツールのネットワークタブを見れば、外部への通信が発生していないことを確認できます。

本ポリシーの変更

データの取り扱いを変更する場合はこのページも更新します。変更の履歴はリポジトリのコミット履歴で確認できます。
